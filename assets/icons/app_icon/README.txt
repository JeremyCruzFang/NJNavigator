App Icon Assets
===============

Drop the four PNG icons into this folder using exactly these filenames so
the homepage Essential Apps section can find them:

  alipay.png   -> Alipay     / 支付宝
  wechat.png   -> WeChat Pay / 微信支付
  amap.png     -> Amap       / 高德地图
  didi.png     -> Didi       / 滴滴出行

Recommended:
  - Square images, transparent or solid background
  - Roughly 128x128 to 512x512 px
  - Same visual size and padding so the row stays aligned

If your source filenames differ, rename them to match. If you would
rather wire different filenames, update <img src="..."> in index.html
at the Essential Apps block.
